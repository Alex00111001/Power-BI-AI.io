# Power-BI-AI.io

Curso práctico de 60 minutos sobre Power BI + IA para profesionales que ya usan Power BI. La página autónoma contiene 24 diapositivas, seis prácticas y prompts que piden soluciones completas desde la primera respuesta.

Ver el curso publicado: <https://alex00111001.github.io/Power-BI-AI.io/>.

La página se genera desde `indice.html` y se publica como `index.html` en GitHub Pages.
