# Power BI de 0 a la automatización con ChatGPT

Curso práctico de 120 minutos orientativos sobre Power BI + IA para profesionales que ya usan Power BI. La página autónoma contiene 28 diapositivas, seis prácticas y ocho bloques 01–08 desde el contrato hasta una conclusión y solución comprobables. La preparación y auditoría se entrega como un script M completo; las medidas DAX se entregan como conjunto. Después de los cinco hallazgos de P06 el informe visual de P07 y las hipótesis de P08, en el bloque 07 mediante P10, la IA genera desde cero un script Python del alumno, que contrasta archivos y referencias sin modificar CSV ni esperados. Python no ejecuta M ni DAX; el alumno confirma los resultados en Desktop.

El laboratorio entrega `Productos.csv`, `Regiones.csv` y `VentasOrigen.csv`, con nombres que coinciden con las consultas correspondientes.

Ver el curso publicado: <https://alex00111001.github.io/Power-BI-AI.io/>.

La página se genera desde `indice.html` y se publica como `index.html` en GitHub Pages.
